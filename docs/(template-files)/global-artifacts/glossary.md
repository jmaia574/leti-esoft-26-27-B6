# Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**

Column "TEA (PT)" is optional. If the team does not intend to use it, then remove it.

(Complete according to the provided example)

| **_TEA_** (EN)                      | **_TEA_** (PT)                          | **_Description_** (EN)                                                                    |                                       
|:------------------------------------|:----------------------------------------|:------------------------------------------------------------------------------------------|
| **Administrator**                   | **Administrador**                       | Person responsible for carrying out various business supporting activities on the system. |
| **ADM**                             | **ADM**                                 | Acronym for _Administrator_.                                                              |
| **Barcode**                         | **Código de Barras**                    | Code generated by an external API to identify and track samples.                          |
| **Chemical Laboratory**             | **Laboratório Químico**                 | Laboratory located at headquarters where chemical analyses are performed.                 |
| **Client**                          | **Cliente**                             | Person who requests tests, provides samples, and views medical results.                   |
| **CLT**                             | **CLT**                                 | Acronym for _Client_.                                                                     |
| **Clinical Analysis Laboratory**    | **Laboratório de Análises Clínicas**    | Local facility responsible for client reception and sample collection.                    |
| **Clinical Chemistry Technologist** | **Técnico de Química Clínica**          | Person responsible for analyzing samples and recording test results.                      |
| **CCT**                             | **TQC**                                 | Acronym for _Clinical Chemistry Technologist_.                                            |
| **Diagnosis**                       | **Diagnóstico**                         | Medical evaluation written by a specialist doctor based on test results.                  |
| **Lab Order**                       | **Requisição Médica**                   | Medical prescription specifying the required tests and parameters.   
| **Blood Test**                      | **Análise ao Sangue**                   | Clinical test that measures blood parameters, such as Red Blood Cells (RBC), White Blood Cells (WBC), and Platelets (PLT). |
| **Chemical Analysis**               | **Análise Química**                     | Process performed at the central chemical laboratory to obtain the results of the parameters associated with a registered test. |
| **Citizen Card Number**             | **Número do Cartão de Cidadão**         | Identification number requested by the receptionist to identify a client when registering a test. |
| **COVID-19 Test**                   | **Teste de COVID-19**                   | Clinical test characterized by a single parameter indicating a positive or negative result. |
| **Date of Prescription**            | **Data da Prescrição**                  | Date on which a doctor prescribes a laboratory test, recorded as part of the registered test information. |
| **Diagnostic Report**               | **Relatório de Diagnóstico**            | Written report prepared by a specialist doctor following the diagnosis. The client can access the test results only after this report has been prepared. |
| **Email Notification**              | **Notificação por Email**               | Email informing a client that their test results and diagnostic report are available in the application. |
| **Employee**                        | **Funcionário**                         | Member of UK Labs staff responsible for performing activities according to their assigned professional role. |
| **Medical Lab Technician**          | **Técnico de Análises Clínicas**        | Healthcare professional responsible for collecting biological samples from clients and registering them in the system. |
| **NHS**                             | **Serviço Nacional de Saúde Britânico** | Acronym for _National Health Service_, the public healthcare system referenced in the project. |
| **NHS Number**                      | **Número do NHS**                       | National Health Service identification number associated with a client during registration. |
| **Notification**                    | **Notificação**                         | SMS and/or email alert sent to a client when the clinical analysis results and specialist doctor's report become available. |
| **Parameter**                       | **Parâmetro**                           | Characteristic measured during a test, identified by a unique code, name, description, metric, and reference values when applicable. |
| **Parameter Result**                | **Resultado de Parâmetro**              | Value obtained for a specific parameter during chemical analysis, recorded together with the date and time of the analysis. |
| **Receptionist**                    | **Rececionista**                        | Staff member responsible for registering new clients and prescribed tests, including prescription and sample collection information. |
| **Reference Values**                | **Valores de Referência**               | Minimum and maximum reference values associated with a test parameter, when applicable. |
| **Registered Test**                 | **Teste Registado**                     | Specific clinical test registered for a client, associated with a test type, prescription date, sample collection date, and laboratory. |
| **Sample**                          | **Amostra**                             | Biological material collected from a client, such as blood, urine, or a swab, to perform a clinical test. |
| **Sample Collection**               | **Recolha de Amostras**                 | Process in which a medical lab technician collects biological samples and records them in the system. |
| **Specialist Doctor**               | **Médico Especialista**                 | Doctor responsible for examining chemical analysis results, making a diagnosis, and preparing the diagnostic report. |
| **Test Type**                       | **Tipo de Teste**                       | Definition of a clinical test, characterized by an internal code, an NHS code, and a description identifying the sample collection method. |
| **TIF**                             | **Número de Identificação Fiscal**      | Tax Identification Number collected during client registration and used to facilitate sorting or searching clinical analysis results. |
| **UK Labs**                         | **UK Labs**                             | English company operating a network of clinical analysis laboratories and a central chemical laboratory located in London. |
| **UKLabsMS**                        | **Sistema de Gestão UK Labs**           | Software system designed to manage laboratory information, clients, clinical tests, sample collection, chemical analyses, and diagnostic reports. |
